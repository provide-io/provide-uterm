# provide-uterm-go

Go port of the provide-uterm terminal session platform, wire-compatible with
the Python implementation. Module path:
`github.com/provide-io/provide-uterm/packages/provide-uterm-go`.

## Compatibility contract

The Python packages remain the reference implementation. Every Go package
that touches a wire format or observable text transformation is proven
against CPython with a **differential corpus**: a generator script runs the
Python code (via `uv run` at the repo root) over a corpus of inputs, records
outputs, and the Go tests must match — byte-for-byte where the format demands
it. A deterministic subset of each corpus is committed under the package's
`testdata/` so Go CI re-verifies parity without a Python toolchain.

Highlights:

| Package | Parity evidence |
|---|---|
| `controlchannel` | DLE/STX codec round-trips against Python both directions |
| `frames` | 24 golden wire frames generated by the Python builders |
| `ctrlmsg` | 544-case HMAC identity-signature corpus (CPython-exact canonical JSON incl. float repr) |
| `vt` | 911-case full-state differential vs pyte (0 mismatches), 211 goldens |
| `screen` | 14,388-case differential (normalize/CP437/extractors) |
| `ansi`/`colors` | 25,728-record token/SGR corpus, byte-exact |
| `emulator` | Snapshot goldens from the Python `TerminalEmulator` |
| `deckmux` | Presence/identity wire goldens incl. HMAC verification |

## Dependencies

Deliberately small, preferring maintained libraries over 1:1 ports where the
wire format is not at stake:

- `github.com/provide-io/provide-telemetry/go` — logging/tracing. Library
  packages accept an injectable `*slog.Logger` (what `ptel.GetLogger`
  returns); transports and higher layers call `ptel.GetLogger` directly.
  Never import OpenTelemetry directly.
- `github.com/coder/websocket` — WebSocket client (maintained successor of
  nhooyr/websocket, context-first).
- `golang.org/x/crypto/ssh` — SSH client.
- `modernc.org/sqlite` — pure-Go SQLite for the control plane (no cgo).

The `vt` package is a fresh Go implementation of pyte's observable behavior
(pyte is LGPL; only programmatically generated factual tables and behavior
were derived — see the package doc and the introducing commit).

## Quality gate

```bash
make quality-gate   # fmt-check, vet, golangci-lint, race tests, 100% coverage
```

Every package is held to 100% statement coverage (`COVER_THRESHOLD=100.0`),
`go vet`, `golangci-lint`, and `-race` cleanliness. New files need the SPDX
header block. `testdata/` golden corpora are excluded from detect-secrets
(synthetic test vectors, not credentials).
