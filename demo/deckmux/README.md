# DeckMux Presence

Multiple operators share a single terminal session simultaneously. Each operator's cursor
position is broadcast to everyone else in real time — you can see exactly where each person
is looking. Useful for pair debugging, live support handoffs, and collaborative incident
response.

**What you'll see:** Two browser windows connect to the same session at once. User 1's view
shows User 2's cursor; User 2's view shows User 1's cursor. Both are live — neither is a
replay or a fake background.
