# Session Replay

Step through a recorded terminal session in the browser at your own pace. Scrub forward and
backward through the timeline, filter by event type (output, input, snapshots), or let it
play automatically. Every screen state from the original session is preserved.

**What you'll see:** A terminal session is recorded for 10 seconds while commands run. The
browser then opens the replay viewer: a timeline of events on the left, the rendered screen
on the right, and a scrubber to jump to any point. The demo clicks Play and lets it run
automatically from start to finish.
