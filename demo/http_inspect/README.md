# HTTP Inspection

Route HTTP traffic through provide-uterm's inspect tunnel and watch every request and
response appear in the browser in real time — headers, body, status codes, and timing. No
changes needed on the client side; just point traffic at the proxy endpoint.

**What you'll see:** HTTP requests are sent through the inspection tunnel. The browser UI
shows each request as it arrives, with full header and body detail. Responses are captured
and displayed alongside, giving a live view of traffic flowing through the tunnel.
